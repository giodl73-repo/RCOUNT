# Source and publication scope

The source ZIP contains every tracked blob of this public RCOUNT commit, with
original modes, bytes and SHA-256 records. It includes the complete native
workspace, browser adapter, technical documentation, tests and existing public
fixtures. It excludes Git history, ignored local overrides, build caches, local
user packages and dependencies fetched from outside the repository.

The original RCOUNT MIT grant is preserved verbatim. This release does not
relicense prior material or extend that grant to third-party software or source
data. Existing source/provenance records and terms remain with their files.
Dependency and Rust runtime original notices are distributed separately. Native
RLINE/RPLAN Git dependencies are fetched at the committed native Cargo lockfile
revisions when rebuilding the full native workspace; their source is not mirrored
into this archive or incorporated into the browser verifier's dependency graph.

Interactive examples are existing public golden packages and fifteen synthetic
audit examples generated by RCOUNT's existing native fixture constructors/writer.
They are testing material, not official election records or statistical advice.
Jurisdiction names and method labels in synthetic examples do not establish an
endorsement or a complete implementation of a jurisdiction's audit procedures.

Opening a package keeps its original bytes in the current browser tab and worker.
Inputs are not uploaded, saved between sessions, included in build artifacts or
added to this source download. Saved package bundles are local exports of those
bytes; transcript downloads preserve Rust's serialization without JavaScript
integer rounding.

The full Git archive link is pinned to the build commit. The independently
downloadable source snapshot has its own file list and custody hash in
`build.json`. A dependency notice is not a grant for unrelated research data.
